# 光点轨迹与自动运镜

## 对参考效果的判断

2026 年 10 月 29 日逐帧复核后，本项目采用明确的轨迹条件：**只有存在有效连奏组 slur 或延音链 tie 的音符，才允许在对应连接内部显示发光轨迹。普通相邻音符只显示光点，不因空间相邻、速度快慢、音量、音色或声音时值重叠自动连线。**

| --- | --- | --- |
| 约 2:29 | 不同音高之间的短连奏组出现短弧线，和弦音可分别形成连接 | 按连奏组内的音乐顺序建立局部连接 |
| 约 2:30.6 | 同屏上方青色连奏音符有小弧线，下方分离伴奏的金色光点移动时没有同样的连线 | 光点移动本身不触发轨迹 |
| 约 2:38 至 2:39 | 跨小节的同音延续对应较长的和弦连接线 | 延音链使用持音连接，声音不重复起音 |
| 约 2:53.8 至 2:55.4 | 快速音群也有弧线，相关音群处于连奏范围内 | 快速演奏不排除连奏轨迹，也不单独赋予连线资格 |

这些画面不能唯一确定原作者直接读取了谱面标记，还是使用了原始演奏数据中的持续与重叠关系。本项目已选择曲谱中的显式 slur 与 tie 关系作为连线依据，原作者实现上的不确定性不影响此产品规则。

印刷的黑色延音线和连奏线属于谱面；彩色连接属于动画。音乐关系决定是否允许连接，几何层决定怎样画线，不要求把印刷黑线原样描亮，也不能用几何上“适合连线”代替音乐关系。

## 三种时间与三个视觉对象

- **起音时间**：演奏事件被触发的时刻，用于音符着陆与亮度峰值。
- **按键或演奏结束时间**：门控结束，不等于声音完全消失；钢琴踏板与混响还可继续。
- **印刷锚点激活时间**：延音链中的后续音符仍需被指示，但不重复起音。

对应三类视觉对象：锚定符头的高亮、移动光球、仅在有效音乐连接中生成的发光线。光点可以在没有拖尾的情况下移动；仍在发声的音符可保留低亮高光。发光线区分连奏过渡的短拖尾与延音链的持音长线，两者使用不同的保留时间。休止符可以提供轻量的进度提示，默认不生成发声光球。

## 何时显示轨迹

先判断音乐连接资格，再应用显示模式与几何约束。候选端点必须属于本次演奏中的同一个有效连奏组，或是延音链中明确相接的两个符头。反复展开后的不同演奏次数不能仅因源谱组 ID 相同而互相连接。

全局 `off` 关闭连奏与延音的发光连接，但保留正常光点与声音；`auto` 按下表显示有效连接，并控制密度；`travel` 尽量保留已具备资格的连接，仍受休止、换页、坐标和密度等约束。**任何模式与逐音符覆盖都不能给 slur 或 tie 关系之外的音符补线。** 逐音符覆盖定义为“从该音符或和弦锚点出发的连接”，可以关闭或调整合格连接；全局 `off` 优先。

| 情况 | 默认视觉 | 判断理由 |
| --- | --- | --- |
| 没有 slur 或 tie 的普通相邻音符 | 光点按各自时间出现、移动或闪光，不连线 | 相邻关系不构成连线资格 |
| 同一有效 slur 组内的相邻音符 | 过渡时显示短弧线，结束后短暂残留并衰减 | 连奏允许多个真实起音，轨迹表现衔接 |
| slur 组内的快速音阶或琶音 | 保留小弧线，按密度缩短历史长度或减少轨迹数 | 速度只影响显示细节，不产生资格 |
| 同音高重复、具有显式 slur | 可短弧连接，各音仍分别起音 | 同音高连奏不等于延音 |
| 同音高重复、没有 slur 或 tie | 各次光点分别闪光，不连线 | 不能只按音高相同推断延续 |
| 位置基本重合 | 默认脉冲；只有已合格的 slur 连接可选小回环 | 不为普通重复或反复回跳增加装饰线 |
| 不属于延音链的普通长音 | 着陆后持续弱光或脉冲，不画持音连接 | 时值长本身不构成连接关系 |
| tie 延音链 | 一次起音，按进度指示多个符头，显示相应的持音长线，结束后衰减 | 同音持续，不因视觉转移重新起音 |
| 无连接关系的断奏、重音或分离伴奏 | 独立的着陆闪光，不连线 | 奏法或强度本身不产生连接资格 |
| 显式 slur 内同时存在奏法标记 | 保留组内资格，奏法只调整闪光与包络 | 不按单个重音或断奏标记重新猜测分组 |
| 两音间有显式休止 | 不跨休止连线，之后重新判断所属关系 | slur 可以继续属于同一乐句，但显示连接在休止处断开 |
| 合格连奏的时间或空间跨度过大 | 可淡出后重新进入，不强行飞越空白 | 几何约束只能抑制连接，不能额外创建连接 |
| 同时发生的和弦 | 每个音都有光点；只在明确的 tie 配对或同一 slur 组内部建立有限连接 | 不把 n 个音连接到下一和弦全部 m 个音 |
| 不同声部、不同逻辑演奏轨道 | 默认分开计算，不按最近音高跨轨串接 | 需要明确且受支持的音乐关系，不能由几何匹配补造 |
| 同声部跨谱表 | 只有既有 slur 或 tie 关系才保留候选，再检查距离与遮挡 | 跨谱表不取消音乐关系，也不自行创建关系 |
| 换行、换页或播放跳转 | 分段淡出与重新进入，配合镜头过渡；语义身份保持 | 避免穿越整张纸的大弧线，延音不因此重新起音 |
| 音源尾音、踏板或时值重叠 | 保留适当的光晕衰减，不自动补连接 | 声音持续或重叠不能替代曲谱连接标记 |

关系缺失、端点无法解析或互相矛盾时，报告并降级为光点；不从音频能量、频率或 MIDI 时值重叠猜测轨迹。后续单独导入 MIDI 时也沿用这一规则，缺少明确连接数据就不自动连线。

首版不为普通长音添加轨迹回环。延音持音线在对应连接的演奏区间内按进度显现与保持，结束后衰减；不能套用短拖尾历史长度，把跨小节的连接裁成一小截。

## 候选连接与和弦处理

1. 从原谱解析 `slurGroupId`、`tieChainId` 和明确的端点，按实际演奏展开成 `relationInstanceId`。跨系统的 continue 标记保持原组身份，反复与跳转不能把不同演奏次数错误拼接。
2. 只在同一次有效 slur 组内按音乐顺序建立候选；tie 按同音延续的明确配对建立持音连接。几何匹配不能为关系之外的相邻音符创建候选。
3. 同声部同一 onset 的音符形成和弦组。slur 内的和弦可按音高与纸面距离寻找有限、单调的对应；tie 必须保持原谱实际音符配对，不能为了画面顺滑改配到别的和弦音。
4. 延音链的锚点转移另建视觉事件，不能当成新发声和弦。同一对端点同时属于 slur 和 tie 时优先使用延音连接，避免叠加两套线或重复起音。
5. 完成音乐资格检查后，再应用休止断开、跨页分段、逐音符关闭、坐标和密度约束。`maxTrailLanes` 只决定显示哪些合格连接，不改变声音；被隐藏的线也不能重新匹配到无关系的音符。
6. 匹配不可靠时只显示光点并报告。只调整音色、音量、配色或纯音频尾音，不改变 slur 与 tie 的连接资格。

短拖尾历史长度可先在 120 至 350 ms、弧高在约 0.5 至 3 个谱线间距内调校；这些是美术原型参数，不是原片已测出的触发阈值。较短时长可压缩曲线表现，较大跨度可抑制或分段；不能把固定时长上限套到真实延音链上。

## 几何与时间

以下过渡公式仅用于已经通过资格检查的 slur 候选 A、B。设起音为 `tA`、`tB`，纸面锚点为 `pA`、`pB`，纸面朝上的法线为 `n`。光球必须在 `tB` 到达 B，而不是音频已经响起后才开始飞向 B。

```text
depart = max(tA, tB - maxTravelSeconds)
u = clamp((t - depart) / (tB - depart), 0, 1)
p(u) = (1-u) pA + u pB + 4 h u (1-u) n
```

起飞前可停留在 A。在三维斜视下，法线高度形成空间弧线；近正面阅读预设需混入适量纸面内的弯曲，避免弧高只改变深度而看不见。距离极小、时间为零或坐标无效时不建立该路径。

连奏短拖尾由 `p(t - age)` 解析采样构成，透明度随 age 衰减，并在规定历史长度后归零。不能只把“上一屏幕帧”的位置存入数组，因为这会让低帧率预览与 60 fps 导出画出不同的线。

延音持音线使用链内相接符头及对应的印刷锚点激活时间，沿曲线显示延续进度，并在该连接结束后衰减。后一个符头没有独立 note on，不能借用“下一次起音”驱动它，也不能以线条长度推算音乐时值。暂停、定位和离线导出都从绝对时间重建这两类线的状态。

同一像素中可能聚合多个音符，亮度要做受控叠加与色调映射，避免白色亮斑吞掉音符。默认按声部分配稳定颜色，乐器更换不改变声部颜色；用户可改成按乐器配色。

## 纸面与渲染

画面分为静态乐谱纹理、纸面材质、音符局部光场、动态光球和拖尾。固定字体和 SVG 栅格化参数保障谱面清晰。首版保持演奏区与邻近谱面的清晰度，不加景深模糊；景深作为后续材质选项，不能遮盖关键谱线。

采用谱面局部坐标生成全部锚点，先转换为世界坐标，再经相机投影。不在屏幕坐标画一套轨迹、纸面世界坐标再画一套光点。首版用受控的纸面局部照明、分层高斯光晕和线条羽化形成发光效果，保持黑色谱线可读；不依赖全屏 Bloom 把整张纸一起冲白。

## 自动运镜

运镜先离线生成 `CameraPlan`，播放时只按时间取样。输入为当前发声与即将起音的锚点、声部优先级、小节和系统边界、页码与可见轨迹。不能让相机每帧追逐一个瞬时光点，否则快速音群会引起抖动。

### 清晰跟谱

近正面显示当前乐谱系统，并为下一系统预留空间。水平位置保持稳定；需要换行时在合适的小节边界平缓向下移动。阅读优先，不追求每个光点都处于正中心。

### 电影纸面

采用受限倾角与透视。默认保持当前系统的稳定横向构图，较强运动幅度允许靠近局部小节；约 1.2 秒前瞻用于准备过渡。多谱表同时演奏时，取相关谱表的包围区域，不能只放大旋律而裁掉钢琴低音光点。声部过多时拉远或显式选择关注声部；被排除的声部继续正常发声。

### 规划步骤

1. 按乐句、小节、系统和页边界生成镜头候选，避免在高密度音群中频繁换镜头。
2. 对每个时间窗计算当前锚点、未来锚点和弧线最高点的包围区域，添加安全边距。
3. 以可读性为硬约束求相机位置、目标与视野，用三次曲线平滑位置。首版固定受限倾角，电影纸面使用透视投影，清晰跟谱使用正交投影；后续若引入变化朝向，再使用四元数插值。
4. 限制速度、角速度和加速度；使用固定时间参数的 easing，不能依赖上一个实际绘制帧的 dt。
5. 换页或反复回跳优先拉远、过渡后再靠近，必要时短交叉淡化。页上没有合理连续路线时不强行飞越空白。
6. 用导出比例重新检查构图。同一套横屏相机不能简单裁成竖屏；镜头须按目标画幅重算。

相机运动幅度为用户选项，提供锁定镜头和降低运动模式。默认将主要演奏锚点保留在画面安全区内，避免镜头穿纸、翻转、接近侧面或使文字过度缩小。具体速度和可读字号在视觉原型中用实际导出画面验收。

当前过渡先平滑扩大到前后两个构图矩形的并集；新小节开始前仍容纳旧小节，新音开始后保留短释放区间，再缩至新构图。不能提前把尚在演奏的前页移出画面。“锁定全页”保持当前页的全页构图，页码变化时切到下一页，避免一直停在首页。

## 可复现要求

视觉状态定义为 `F(RenderPlan, absoluteTime, seed)`。所有随机扰动使用固定种子和对象 ID；镜头和轨迹不依赖播放历史。导出第 3000 帧、直接定位到该时间以及从头播放到该时间，应该得到相同的几何状态。

同一机器与相同渲染器版本下可比较未编码帧。跨 GPU 和不同系统版本不承诺位级相同；接受阈值应针对投影位置、亮度范围和构图定义，而非要求所有像素完全一致。
