# 实施计划与验收

## 实施顺序

先做能否成立的技术验证，再建立完整产品。P0 结束必须能从结构化曲谱输出带声音和光点的真实视频，不能只交付静态 UI 或一个无声动画。

| 阶段 | 交付物 | 通过条件 | 初步工作量 |
| --- | --- | --- | --- |
| P0 技术原型 | Mac 最小窗口、一个导入器、排版锚点、双乐器、Metal 预览、短视频导出 | 30 至 60 秒原型成片；原谱 ID 与符头对应；脉冲同步通过 | 1 至 2 人周 |
| P1 文档与曲谱核心 | `.scorefilm`、MusicXML 语义索引、能力报告、保存与迁移框架 | 原创样例和兼容性语料可回读；未知内容不丢失 | 2 至 3 人周 |
| P2 演奏与配器 | 反复展开、时间线、钢琴和小提琴、分段路由、暂停定位 | 延音、踏板、同音重叠、换乐器边界、速度变化正确 | 2 至 3 人周 |
| P3 视觉与镜头 | 两种主题、光点、轨迹规则、纸面材质、自动运镜与选项面板 | 两段参考的主要视觉行为逐项对照；复杂段落不失焦或抖动 | 3 至 4 人周 |
| P4 成片导出 | 1080p 30 与 60 fps、音轨、进度、取消和错误处理 | 短片与长片解码验证；无缺帧、漂移或尾音截断 | 2 至 3 人周 |
| P5 产品收尾 | 文档操作、自动保存、键盘与辅助功能、实际设备与性能验收 | 首版验收矩阵关闭，安装与启动证据齐全 | 1 至 2 人周 |

合计约 11 至 17 人周，属于在熟悉 Swift、音频与图形开发的前提下的规划估算，不是工期承诺。初次接触乐谱排版、音源调校或 Metal 时需要增加时间；高拟真弦乐、完整打谱器和 PDF 识谱不在此估算内。P0 后依据真实瓶颈重新估算，不按阶段表机械承诺交付日期。

## P0 的技术门槛

1. **排版映射。** 固定版本 OSMD，证明普通音符、同音和弦、延音、连音组、跨谱表和换页后的 sourceNoteId 到符头坐标映射；导出图片和锚点使用同一坐标变换。无法稳定映射时评估 Verovio，不在 UI 中按图形顺序补丁匹配。
2. **音频。** 确认可分发的钢琴与小提琴音源，验证 sampler 离线模式、事件边界、note off 归属与声音尾音。接口调用成功不等于听感通过。
3. **渲染。** 在纸面透视、光晕和动态轨迹下保持谱面清楚；同屏验证连奏组有短弧线、延音链有持音连接、分离伴奏仅有光点，确认纹理分辨率和相机约束。
4. **导出。** 从实际 PCM 和 Metal 帧生成 1080p60 MP4，通过解码后的同步、帧数、PTS 与声音检查。
5. **可复现。** 从头播放和任意时刻取帧得到相同几何状态；反复展开不让 ID 错位。

## 语料与测试矩阵

| 风险 | 必备测试输入 | 应有结果 |
| --- | --- | --- |
| XML 顺序误当时间 | 同小节两个 voice，包含 backup、forward 与 chord | 多声部同时开始，和弦不被串行播放 |
| 连音与舍入 | 三连音、五连音、附点与中途改变 divisions | 有理拍值准确；长段没有累计采样误差 |
| 不同时间轴 | 印刷重复编号、反复、第一第二结尾、跳转 | 源谱身份不变，演奏 occurrence 独立且终止 |
| 延音与连奏混淆 | 跨小节 tie 和普通 slur | tie 无第二次起音，slur 中音符照常触发 |
| 配器边界 | 钢琴长音跨越小提琴路由边界 | 原钢琴音自然释放，新音由小提琴承担 |
| 同音高相互关闭 | 两 voice 同时演奏同一 MIDI note，结束时间不同 | 其中一个 note off 不误关另一个 |
| 踏板 | note off 后继续踏板，边界处换乐器 | 旧实例接收正确释放，新实例不继承脏状态 |
| 速度解释 | 分段恒速、小节中间速度变化、渐慢、延长记号 | 声音和画面共用同一转换，不因排版库时序限制丢失 |
| 移调与编号 | 降 B 乐器、八度移调、GM program 1 与 41 | 印刷音高与实际音高正确；program 不偏移一位 |
| 轨迹误连 | 休止、断奏、同位重复、换行、跨谱表、密集和弦 | 按规则断开、缩短或配对，无跨声部乱连 |
| 连线资格 | 同一段音高与时值，分别有无 slur；同屏连奏与分离伴奏 | 只有有效 slur 或 tie 内部允许连线，普通相邻音即使移动也不拖线 |
| 连奏组边界 | 两个连续但独立的 slur 组、组尾与下一普通音、组内显式休止 | 不跨组或跨休止补线，反复中的不同关系实例不混接 |
| 延音持音线 | 跨小节 tie 与无 tie 的普通长音 | tie 持音连接按演奏区间保持且不重复起音；普通长音只有持续光点，长线不被短拖尾时长裁短 |
| 模式与覆盖 | 无关系音符设置 travel，合格连接设置 off，全局 off 加逐音符 travel | travel 不能补造关系，off 正常关闭，全局 off 优先 |
| 声音与资格解耦 | 相同关系更换钢琴或小提琴、调节力度和纯音频尾音，或仅增加 MIDI 重叠 | 连线资格不变；音色、音量、尾音和重叠不能产生新连接 |
| 镜头抖动 | 高速重复音、双手相距较远、换页和回跳 | 主演奏区保留在安全区，运动连续且不穿纸 |
| 定位状态 | 定位到长音、踏板、混响或拖尾中间 | 缓存 PCM 与解析视觉状态一致 |
| 视频时间 | 30 与 60 fps、音符恰落在帧边界、5 分钟曲目 | PTS 单调，音轨完整，相对同步误差不累计 |
| 失败与取消 | 磁盘不足、取消、关闭窗口、设备切换、字体或音源缺失 | 有清楚错误，不损坏项目和既有成片 |
| 不可信输入 | ZIP 路径穿越、过大解压、XML 外部实体、未知版本 | 提前拒绝或限制，不访问外部路径和网络 |
| 保存与兼容 | 未知 XML 节点与 JSON 扩展，编辑后另存 | 原始内容与扩展保留，迁移可追溯 |

测试优先覆盖上表的真实风险；不为了数量给每个 UI 参数新增镜像测试。兼容性语料可采用自制小谱和许可明确的公开谱，不能把项目参考视频中的音乐直接视为可随应用分发的测试素材。

## 视觉验收

两种预设分别与参考录屏中的有效成片区域对比，裁掉手机状态栏、黑边、播放器按钮和屏幕录制标志。

- 光点中心落在符头，和弦每个音能独立指示；谱面重排后仍然对齐。
- 光球在音乐事件时刻着陆；静音、独奏、配器变化后语义一致。
- 两种预设共用连线资格规则：slur 组内可显示短弧线，tie 链可显示持音长线；普通相邻音、组间过渡和分离伴奏只显示光点。
- 对照第二段约 2:29、2:30.6、2:38 至 2:39 的片段验收短连奏、同屏有线与无线、跨小节延音；快速连奏不过曝，休止与换页不乱连。
- 纸面有柔和的局部照明，当前演奏谱线和符号可读，不被大光斑或景深吞没。
- 相机能跟随乐谱前进，双谱表同时演奏时构图合理，换行或反复跳转舒适。
- 未编码离屏帧与同时间预览在同等质量参数下匹配；编码后的色彩和锐度单独验收。

## 性能目标

原型阶段先记录实际 Mac 型号、芯片、内存、系统、SDK、窗口尺寸、导出参数、音源与曲谱哈希，再建立基线。以下是待测目标，不能写成当前已达到的指标：

| 指标 | 首轮目标 |
| --- | --- |
| 标准预览 | 1080p，60 fps；不足时允许预览降为 30 fps，声音和时间不降精度 |
| 标准曲目 | 5 分钟、最多 8 个逻辑 part、约 32000 个音符；另测高密度压力谱 |
| 预览稳定性 | 典型片段 p95 帧耗时目标不超过 16.7 ms；长时间记录掉帧与内存趋势 |
| 内存 | 分页瓦片与有限帧队列，目标使标准场景常驻内存控制在约 1 GB 内，按实测调整 |
| 音画同步 | 测试音源导出相对误差不超过一帧加一个采样；5 分钟无累计漂移 |
| 导出速度 | 先记录实际耗时与峰值内存，不预先承诺快于实时 |
| 首次准备 | 分别记录解析、排版、合成耗时；据此决定是否需要分段准备 |

导出性能只统计一次真实任务从开始到完成的墙钟时间。不同并行阶段的累计 CPU 时间不能当作用户等待时间。

## 发布前的范围内检查

使用实际计划支持的 Mac 设备测试安装、启动、打开、保存与导出。先验证 Apple Silicon；如果决定支持 Intel，必须增加相应运行证据，不能由通用源码或编译选项推断兼容。iOS 需要独立的设备、音频会话和热管理验收。

音源与字体的分发许可、第三方库固定版本、隐私和文件访问范围需在发布方案中落实。此阶段只定义需求，不修改签名、entitlements、系统版本或商店配置。
