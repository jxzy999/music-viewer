## 2026 年 10 月 29 日轨迹条件修订检查

已将连线资格统一为显式 slur 连奏组与 tie 延音链，移除“普通相邻音符默认连线”和“slur 只作为风格加分”的旧规则。同步架构中的关系身份、格式与 Schema 字段说明、示例预期及验收要求；音频、自动运镜和其他产品范围保持原有方案。

本次静态检查覆盖：

- 文档本地链接、代码围栏、UTF-8 与行尾空白，以及相互矛盾的旧规则表述。
- Schema 可解析；本次仅补充 description，不改变 JSON 的字段、枚举与结构约束。示例 JSON、MusicXML、manifest 和 ZIP 内容保持一致，包内哈希有效。
- 示例原谱包含两组 slur 与一条 tie 连接。组内有六对相邻连奏音，延音链有一对同音符头；第一小节末尾重复 E4、第三至第四小节的组间过渡和整个 P2 伴奏不具有连线关系。

上述检查仅确认文档与示例数据的关系一致，尚未运行轨迹编译器或渲染器；短线、长线和无线对照的实际效果仍按验收矩阵验证。
